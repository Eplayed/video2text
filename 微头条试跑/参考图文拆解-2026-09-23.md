## 打法拆解（值得抄的）

### 1. 结构模式
- **封面 = 官方 Logo + 大字承诺**：WoW 圆形徽标居中 + 紫色描边大字「无限最全 副本攻略」——一眼识别游戏 + 一句话给收藏理由
- **一图一主题**：每个副本一张任务卡，46 图打包成「大全」制造收藏冲动（进主页看其他内容还要关注）
- **超具体信息**：坐标（贫瘠之地 46,74）、等级段（13-18级）、NPC 名、阵营专属（联盟/部落差异化路线）

### 2. 视觉语言（关键差异）
竞品的图不是"通用暗金信息图"，而是 **WoW 原生视觉**：
- 仿游戏内任务日志 UI：暗棕皮革质感面板 + 鎏金雕花边框 + 菱形角饰
- 金色发光路线 + 编号节点的手绘地图（羊皮纸风格）
- 阵营徽章（部落红/联盟蓝）、火把、卷轴等游戏元素
- 步骤流程卡：编号徽章 + 箭头连接（前置→接任务→进本）

### 3. 内容卡固定结构（副本任务卡示例）
```
标题：领主大厅（金色大字）
副标题：联盟专属 | 13-18级 | 铁炉堡地底（一行三要素）
正文：编号任务列表 4-5 条（图标 + 任务名 + 一句话怎么做）
底部：重点提示条（"前期优质蓝装，一次副本可全部做完"）
```

### 4. 合规发现
46 图攻略大全带「**豆包AI生成**」水印——竞品就是 AI 生成的且公开标注。我们的「AI 辅助生成」声明不是劣势，是行业标准做法。

## 我们模板 v2 改造方向

| 现状（v1） | 改造（v2） |
|---|---|
| 通用暗色+金色信息卡 | WoW 原生皮：鎏金边框面板、菱形角饰、暗棕皮革底纹（CSS/SVG 自绘） |
| 封面=纯文字大标题 | 封面=游戏徽标位 + 「最全XX」式大字承诺 |
| 通用编号列表 | 编号徽章 + 行内图标 + 三要素副标题行（阵营/等级/位置） |
| 无阵营概念 | 部落/联盟双色区分（module-4 红 / module-2 蓝 正好可用） |

内容结构不变的部分：决策化整合三件套（变化对比/影响/行动）继续是内核——竞品的「任务卡」本质也是"照着做就行"的行动清单，和我们的「行动建议」同构。

## 版权注意

竞品直接使用暴雪官方 Logo 和角色立绘。头条游戏区这是普遍做法（同人生态灰色地带），但：
- **建议路径**：视觉风格自绘致敬（金边/羊皮纸/菱形角饰/阵营色），游戏名和机制描述是事实信息不受版权保护
- 封面官方 Logo 想用可以用（识别度收益大），但要知道这是灰色地带，暴雪理论上有投诉权（实践上对同人引流内容基本不管）
- 角色立绘尽量不用 AI 生成暴雪角色形象，风格化元素替代
