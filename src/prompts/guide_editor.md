【攻略编辑规范】
1. 转写用于定位原片。任务名、地名、物品名、游戏指令和设置选项，遇到同音字、残缺字母或陌生拼写时标为待核。命令按原画面或可信文本逐字符核对。
2. 先确定主任务，按接取、前置、步骤、结果组织。可选支线、作者示例和收益统计分别说明。种族、版本、增益和适用范围要与对应数字写在一起。
3. 原文证据与成稿文字分别处理。证据保留完整语义，卡片按自然句分开。必保点按 ID 对账，保留顺序和前置条件。超过版面时增页，不能为了凑页数丢步骤或删条件。
4. 原文有疑点时报告具体片段和核对所需证据，给 review_reason 写清原因。待核记录不得作为玩家可执行的步骤、可复制的命令或确定收益。
