## 改动

- 原意母稿整组拆稿与单页重拆使用独立提示词分支：卡片数按内容决定，并列清单保持并列；保留必保点、主体、条件、否定词，不为了画面或“去过程词”补事实。原有非母稿分支继续使用原提示词。
- 有真帧时，母稿分支不再提示固定 2–3 张卡；无对应画面时允许文字页，缺关键画面交编辑补图。
- 单条 `toutiao_mix` 整理稿不能再从旧头条卡片入口生成，界面提示走“AI 海报”原意核对；多源旧合集保留旧入口并明确标成旧卡片。历史包仍能只读，展示“旧版，未做新版校验”。
- 单源原意图文的角色分支写入 `docs/角色流程-新图文原意保留.md`；项目内本机角色技能同步了简短分支提醒。技能目录被 Git 忽略，跨机应以项目文档为准。
