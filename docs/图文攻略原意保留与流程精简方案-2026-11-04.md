# 图文攻略：原意保留与流程精简方案

日期：2026-11-04。状态：方案完成，尚未实施。

迭代准备已完成：后续需求以 [PRD v1.0](PRD-图文攻略原意保留-v1.0-2026-11-04.md) 为准，排期见 [迭代计划](迭代计划-图文攻略原意保留-2026-11-04.md)，实施状态见 [任务单](任务单-图文攻略原意保留-2026-11-04.md)。本方案保留作为业务背景，不重复维护任务状态。
用户决定：旧稿不返修；只优化后续图文攻略。本文取代此前「先返修三篇」的执行建议。
范围：视频采集后的整理、拆页、配图及头条/公众号输出。不是渠道策略权威源，不在本文件另存策略常量。

## 一、产品目标与取舍

已成型的优质视频通常已经完成选题、取舍、解释。默认任务改为「把这份信息变成便于阅读和保存的图文」。忠实于原意与事实是否正确分开检查：保留作者观点归属，不把作者说过等同于客观正确。

优先级：原意和条件完整 > 核心突出 > 手机可读 > 页面变化。原视频是教程就保留操作次序；是并列清单就保留清单；是观点就保留观点与依据。默认沿用原题范围，不强迫找新角度、制造争议或增加个人判断。

单条材料为默认；只有明确缺少必要条件或需核对版本时补充来源。多素材专题仍可用，但作为独立入口，逐项保留来源和分歧，不让每篇都走合集与重新论证。

## 三、新流程：两次内容加工，一次集中预览

`原片/完整转写＋时间戳 → 原意母稿 → 分页配图 → 自动校验＋集中预览 → 人工发布`

默认只保留两次生成型加工：第一次提取原意母稿，第二次短句化与分页。ASR、按需术语核对、证据核验不计作文章重写；出现具体错误才定点重做对应句/页，不循环整篇改写。新增校验尽量复用现有检查与证据记录，不新建多套规则或多轮人工审批。

### 第一次：原意母稿

这是既有整理稿的替代图文模式，不是新增一份中间长文。

保留：这篇解决的问题、原作者答案、支撑答案的步骤/机制/比较、适用条件、关键名词与数值、必要例外。仅删口头停顿、重复解释、与主题无关的带货/寒暄等；能突出作者具体说法时保留自然口语，不复制虚构亲历。

系统先给一个可直接使用的默认信息层级：

- 必须保留：核心答案、完成动作所需步骤、影响结论成立的条件。数量由内容决定。
- 支撑内容：解释、演示、例子；可精简但不能让结论失去依据。
- 可省略：重复句和离题信息，内部记录省略原因。

结构化记录建议（沿用当前记录扩展，实施前核现有契约）：

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| main_question | 字符串 | 原素材实际解决的问题，不用排产题反过来改素材 |
| core_answer | 字符串 | 原作者的核心答案，保留必要的观点归属 |
| content_type | 枚举字符串 | 操作/改动/比较/观点/清单，决定默认组织方式 |
| points | 对象数组 | 每条含稳定 id、原句、短句、重要性、主体、条件、source_id、时间段与证据状态 |
| source_spans | 对象数组 | 原片完整转写各段的处理状态，长视频不能漏尾段 |
| omitted | 对象数组 | 被省略片段与原因；关键缺证内容另列，不悄悄消失 |
| version | 字符串 | 母稿版本，供页面与发布包绑定 |

字段缺失明确为空或待核，不允许模型补全知识。若待核内容决定整篇成立与否，则先核该项；若是非核心细节，可以省略并记录。不能带着矛盾结论继续包装。

### 第二次：页面编排

模型只允许短句化、分组、必要的排序调整和写忠实标题。每个标题/卡片/配文句绑定 point_id；额外官方核实内容绑定独立来源，不混作原作者原话。

第一页直接交核心答案和必要条件，可以同时是正文，不强制另占一张封面。后续每页承载一个完整信息组；结尾放最后一个要点或有用的速查，不固定互动页。

| 原材料类型 | 默认写法 | 不能强加 |
| --- | --- | --- |
| 操作教程 | 做什么→入口→操作顺序→成功状态→必要例外 | 泛泛「避坑」、原文没有的按钮/步骤 |
| 改动信息 | 对象→改前/改后→生效条件 | 未经依据的强弱排名与就业预测 |
| 比较选择 | 比较对象→相同维度→条件→原作者结论 | 为了标题把「更适合」写成「必选」 |
| 观点分析 | 谁的观点→依据→成立边界 | 把预测写成结果，把个人经历推广给全部玩家 |
| 信息清单 | 保持原分类与完整条目，必要时索引分页 | 强行凑递进论证和「已改/没改」 |

不设全篇固定页数。初始默认可尝试 3–5 页，但这是排版起点，既非最低要求也非上限；一页能说明就一页。复杂操作允许连续多页。用户主动限页时先反馈哪些内容装不下，不自动删核心。

### 配图与版式

先看这页内容需要证明或示范什么，再在对应时间段选帧；连续步骤可以使用相距不到 12 秒的不同状态，不能机械按时间排除。视觉差异按功能决定，同类步骤可以重复版式。

操作页优先使用可辨认的界面局部、步骤编号、按钮原名及箭头。截图上标的动作必须真实出现。证据图和装饰图分清，装饰不得伪装成操作结果。没有合适证据图时允许文字页，操作性关键画面缺失则提示补帧；不生成假游戏界面。

字号下限以现有移动端可读标准为准，优先扩大正文与关键区域；超长先分页或换内容布局，不自动删句、不无限缩字。大数字只用于真正的关键数值，不因模板有空位就填。

### 自动校验与用户界面

用户主流程保持「生成图文 → 看完整预览 → 确认并导出」，不新增多页填写表。

预览顶部显示：原视频核心答案、必保信息在第几页、具体待核项。点问题可跳原片时间段和对应页面；内部加工记录不印进读者正文。

自动检查两类互相独立的问题：

1. 忠实性：必保点是否全部出现；主体、对象、数值、条件、先后顺序、确定程度是否改变；图片是否对应页面。ID 覆盖只证明有映射，语义是否相等仍需检查，不能用 100% ID 覆盖冒充正确。
2. 事实性：原作者说法是否有适用证据；一手、第三方观点、待核区分显示。现有数值/实名/事实闸保留，未覆盖或未判不能标成全已核。

只对具体不通过的句/页定点调整。用户只在原意不清、关键事实缺证或最终预览时介入，不要求逐句手工贴来源。

## 四、取消、降级、保留

取消默认：完整长文再缩海报；强制重新选角度；为原创增量硬编结论；一律步骤/机制/避坑；强制对比/风险/互动/大数字；固定页数/卡数；每页必须不同；无关图自动补；超长删末位与截句；整篇反复「去 AI 味」。

降级为按需：多素材整合、官方补充检索、独立观点扩写、额外模板变化、单页重写。保留整理身份与来源，不能把忠实转述声称为原创研究。

保留：采集、ASR 与时间戳、已有术语校正、来源留存、真实抽帧、中文排版、渠道尺寸适配、事实与数值检查、人工最终发布、运行版本与历史快照。

旧规则中「每页有图」「相邻不重复版式」曾记录为号主选择；本文建议在新的素材转图模式取消这些默认硬约束，尚未改线上行为。

## 五、实施拆分

| 顺序 | 修改范围 | 交付与验收 |
| --- | --- | --- |
| P0 | 海报与公众号卡片 prompt/schema；裁剪调用链；自动配图回退 | 不再强迫填部件；不删核心点/条件；不补无关帧。接口缺省字段与老包读取兼容，样式变化不触发内容重写 |
| P1 | content_store 图文提取模式、完整原文分段、source/point 关联 | 图文不绕完整长文；每条必保信息有源与页面映射；长文尾段也参与提取；复用现有原始转写和证据链 |
| P2 | 工作台预览、跨渠道产物与校验 | 一份母稿两端分页，头条与公众号各自标题/配文/manifest/审核与发布状态；预览能定位遗漏与漂移 |

P0 降低当前已确认的变味诱因，P1/P2 完成信息保留闭环，不能把仅改提示词宣称为整个方案完成。实施角色为 media-dev；共享文件先核并发归属；按仓库要求进行重启、界面走查与 graphics 门禁。

不改变默认主线之外的公众号长文、面试题等生成模式，不重生成旧稿。换皮肤仅重新渲染；改字号或比例仅重新分页并校验；改内容才重新检查对应信息。

## 六、新内容验收

选择后续 3 条新素材：操作教程、改动清单、观点/比较各一条。旧稿不返修，可仅把已知错误作为隔离测试样例。

- 人工确定每条原片的必保点，新成品全部保留；重要条件丢失为 0。
- 无来源新增结论为 0；观点转确定事实为 0；内容为了版式被截掉为 0。
- 有图的页面逐张相关；缺关键操作图如实提示，不能自动补别的画面。
- 核心答案在首屏可见，目标读者能说出这篇最重要的信息；操作类能沿步骤找到对应界面。
- 两渠道独立验手机阅读与配文，不用渲染测试 PASS 代替语义验收。
- 记录模型调用数、耗时、人工改动与最终费用，验证减少重复生成是否真的提效。

这些是验收目标，尚无执行结果。新稿真实模型质量、手机实测、长文输入边界及生成成本均待实施后验证。
