# 新图文原意保留的角色分支

适用：从单条新素材派生 AI 海报或公众号图片消息卡片。先定头条/公众号渠道，再定本次交付是“原意图文”还是“新写文章”。两渠道审核与成品分开保存。

## 原意图文

1. 原始转写是事实根。先提取可定位的母稿点，标核心答案、必保信息与条件；旧整理稿标题、九节文章骨架和策划角度不能变成事实依据。
2. 只按原文信息类型分页：并列清单保持并列，操作步骤保持先后；卡片数、对照、提醒、互动按内容需要决定。画面必须与当前页事实相关，无关图不补。
3. `media-planner` 的角度三问用于“另写一篇有新角度的稿子”。单源原意图文不为满足角度门改写原结论；可以直接进入母稿提取和卡片编辑。需要原创判断时再回策划，分清其来源。
4. `media-material` 的公众号九节文章档和 `media-writer` 的选题包成稿标准只用于文章交付；图文卡片不能因为这些标准被扩写成文章。公众号文章路径保持原规则。
5. 内容改动后复审对应版本；换皮只重渲染。机器审核通过表示技术闸通过，发布仍需人工看原句、实图、来源说明并在平台操作。

## 旧稿与旧合集

旧包可读，缺原意审核字段显示“旧版，未做新版校验”。旧合集/文章继续原流程；不能把旧包或旧头条卡片入口的结果标成新版原意已核。`V2T_ORIGINAL_GRAPHICS=off` 只暂停新图文任务，不迁移历史数据。
头条旧卡片生成入口只用于多源合集；单条素材进入 AI 海报原意母稿流程，避免从旧整理稿再次卡片化。
