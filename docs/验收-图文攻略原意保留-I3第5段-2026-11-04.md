# I3 第 5 段验收：新图文暂停开关与旧包读取

日期：2026-11-04。范围：AI 海报、公众号卡片、头条卡片的新生成请求；历史图文包读取。

## 交付

- `V2T_ORIGINAL_GRAPHICS` 默认 `on`，设为 `off` 后，AI 海报拆稿/单页重拆/出图、公众号卡片与头条卡片新生成在模型调用前返回 409；已保存草稿与历史包的 GET 仍可用。`GET /api/graphics/original-mode` 返回 `enabled: bool`、`mode: str`、`env: str`。运维方式写入 README。
- 头条、公众号与 AI 海报的历史包读取响应增加 `generation_mode: str`；缺原文/母稿版本或有效审核的包返回 `legacy` 和 `validation_label: str`（“旧版，未做新版校验”）。该字段仅在响应中补，不迁移、回写 manifest。三个详情页显示这句边界。
- 公众号整篇文章路径、采集路径不绑定此开关；发布仍为人工操作。

## 验证

- `python3 scripts/e2e_graphics_mode_i3.py`：`ALL_OK`。关闭时五个生成 POST 拒绝；两类包仍可读；旧 manifest 字节哈希不变；重新开启后入口恢复前置检查；公众号文章路由仍按原要求处理。
- `python3 scripts/agent/ui_graphics_mode_i3.py`：`ALL_OK`。隔离 Flask + Playwright 验证三个详情页的旧版提示。截图：`output/迭代验收/原意保留/I3/旧版包只读提示-隔离界面.png`。

## 边界

- 这一步未改排产策略；现有排产只产出素材/整理稿，不直接调用上述出图接口。
- 头条卡片旧入口在开关开启时仍从 `toutiao_mix` 整理稿做旧式卡片化，尚未用原文母稿；T14 因此保持部分完成，留给 T15 决定旧入口收口。不能把该旧路径标为新版原意已核。
- 未使用真实模型、未生成或发布新成品；T17 三素材六包内容验收仍未完成。
