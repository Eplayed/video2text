# 图文攻略原意母稿｜I2 实现契约

日期：2026-11-04。范围：新生成的头条攻略与公众号图片消息；旧包只读。I1 的 114 号样本两处语义变形是固定反例。

## 调研与取舍

限定 10 分钟查阅高星项目的公开实现：[Haystack DocumentSplitter](https://github.com/deepset-ai/haystack/blob/master/haystack/components/preprocessors/document_splitter.py) 保留源 ID 与分段起点，[LlamaIndex CitationQueryEngine](https://github.com/run-llama/llama_index/blob/main/llama-index-core/llama_index/core/query_engine/citation_query_engine.py) 把回答绑定来源节点。只取“原文偏移＋稳定节点 ID＋回答来源映射”的做法；不引入框架，不复制代码。另参考既有 PRD 中的 [STORM](https://github.com/stanford-oval/storm) 与 [Langfuse](https://github.com/langfuse/langfuse) 方法。

## 真源与存储

- 根输入：`videos.transcript`，多视频按 `source_video_ids` 排序并分别定位。视频标题仅帮助识别题材，不能充当正文事实来源。没有转写则新模式停在“缺原文”，不拿 `ai_summaries.content` 自证。
- 每份摘要在 `ai_summaries.structured_data.guide_mother_v1` 增量保存母稿，保留其他键；不迁表、不改旧成品。更新使用 SQLite 事务，落盘前重查源修订，避免旧请求覆盖新转写。
- `source_revision: str` 为源视频 ID、标题、转写的 SHA-256；`mother_revision: str` 为源修订与已核定位点的 SHA-256。修订变化时原母稿和下游审核失效，不沿用旧 PASS。

## 数据形状（字段名：类型）

- `status: str`：`partial`、`complete`、`failed`。只有所有段成功且至少有一条必保点时为 `complete`。
- `segments: list[dict]`：`segment_id: str`、`video_id: int`、`start: int`、`end: int`、`status: str`、`point_ids: list[str]`、`error: str`；偏移为原转写字符位置，末段必须覆盖到源文结尾。
- `points: list[dict]`：`point_id: str`、`quote: str`（源文逐字片段）、`display_text: str`、`priority: str`（`must/support/optional`）、`subject: str`、`conditions: list[str]`、`modality: str`（`fact/opinion`）、`source_ref: dict`（`video_id/start/end`）。`quote` 找不到或偏移不一致不能登记来源。
- `core_question: str`、`core_answer: str`：仅作编辑导航；原意事实仍须由 `points` 支撑。
- 下游计划增加 `source_revision: str`、`mother_revision: str`、`point_ids: list[str]`；卡片也带 `point_ids`。纯导航或来源尾注允许不绑定，实质句不许靠虚构 ID 凑覆盖。
- `checks: dict`：覆盖检查和语义检查各有 `status: str`、`issues: list[dict]`、`input_revision: str`，不把“模型调用成功”当“原意正确”。

## 处理与失败

1. 按原文标点和段落切到单段上限，每段带精确偏移；逐段提取原句与要点。每段成功即保存。失败后只重跑失败/未处理段，已成功段原样复用。
2. 每条引文必须能按 `source_ref` 在对应原转写逐字读回；段空结果、越界和模型新增引文都为失败，不能宣布“完整”。
3. 头条拆页和公众号卡片只消费完整母稿；提示词要求逐条引用 point_id。覆盖闸检查必保点、非法 ID，语义闸独立对照原句核主体、数量、条件、先后与否定词。任一未判或有疑点，生成停在可编辑草稿，不能标可发布。
4. 编辑、换标题、重拆单页或源文更新后，下游 `input_revision` 改变；生成前重新跑检查。较旧后台结果写回时核对源修订及任务版本，旧结果不能覆盖新母稿或新编辑。
5. 未配置 AI 不影响采集。新图文生成提示“未配置 AI，原意母稿未生成”；公众号文章旧入口不变。公众号本地模板仅能是待核草稿。

## I2 验收

长源文末尾保留、失败段续跑、缺源、原句定位、两个小号/第一个小号的范围纠错、必保遗漏、合法观点、修改后旧检查失效、旧任务晚返回与无 AI 路径均需有隔离测试。I2 只建内核与现有生成链的内容闸；I3 再完成双渠道集中预览与三素材六包人工放行。
